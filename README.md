## ◈ About

Most AI projects do not fail at the idea. They fail at shipping it. Without a system that survives real data and real users, even a strong model quietly dies in a notebook.

I am a final-year B.Sc. Artificial Intelligence student at Shifa Tameer-e-Millat University (CGPA 3.76/4.00), building the pipelines and products that give AI its shape: applied machine learning, computer vision, and NLP systems designed to hold up in production, not just in a demo. My recent work spans a face-recognition event-photo platform deployed on Azure, an MCP server that audits vibe-coded apps for production readiness, and a classical NLP pipeline for lecture transcription, alongside freelance medical-imaging models and an open-source deployment-automation skill for Claude Code.

I currently work as an AI/ML Developer at Aditor Agency, and hold AI internships at FlyRank (Machine Learning track) and AiTec (Artificial Intelligence Technology Centre), Islamabad. I founded the AI Innovation Society at STMU and served as its President before stepping back to focus on my Final Year Project and technical depth.

## ◈ Featured Projects

<details open>
<summary><b>⬡ &nbsp;FaceFind — Face-Matched Event Photo Retrieval System</b></summary>
<br/>

A completed, deployed computer vision system. Attendees join an event with a short code, scan their face, and retrieve only the photos they personally appear in from a connected Google Drive album, without ever seeing anyone else's photos.

| Attribute | Details |
|:----------|:--------|
| **Stack** | FastAPI · MediaPipe · ArcFace ResNet-100 (ONNX) · FAISS · PostgreSQL · Redis · React · Docker |
| **Scale** | 3,252 faces indexed across 299 files on the live deployment |
| **Security** | AES-256-GCM encrypted embeddings, scoped signed file tokens, RS256 JWT with Redis-backed revocation |
| **Deployment** | Live on an Azure Ubuntu VM via a production Docker Compose stack with GitHub Actions CI/CD |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repository-000000?style=flat-square&logo=github&logoColor=white)](https://github.com/sudais-khalid/FaceFind) |

Built as a Computer Vision semester project and taken all the way to a hardened production deployment: real face-matching accuracy tuning, encrypted storage, concurrency fixes, and a working CI/CD pipeline, not a notebook demo.

<br/>
</details>

|:----------|:--------|

| **Team** | Built with two teammates; I own the ProdPush deployment layer |
| **Context** | Doubles as my AiTec internship project, with a research paper in progress |

Submitted as my NLP semester project. The classical pipeline is always the source of truth; an optional Gemini pass may only polish wording, never replace the underlying analysis.
